Evidence · local baseline

How I benchmarked GitNexus, Graphify, and CodeGraph on the same machine.

A controlled, LLM-free harness that runs each tool’s native commands against real repositories — cold, warm, and incremental — without declaring a universal winner.

View snapshot Read source article

Why a benchmark

Features don’t answer “what happens on my machine?”

GitNexus, Graphify, and CodeGraph build useful representations of code, but docs and isolated numbers don’t show what actually runs when you index real repos locally. This project measures wall time, CPU time, and peak RSS under fixed commands — a baseline you can reproduce and extend toward RepoAtlas.

Not a leaderboard. Repositories differ in size, semantics, and work per command. Medians and LOC-normalized diagnostics are starting points, not definitive throughput scores.

Architecture

Separated harness, unmodified references

Three checkouts live under repotlas-references/. repo-benchmark/ owns the experiment; the tools are not patched to share a synthetic CLI.

Workspace topology

Type: architecture · Size: doc-wide · Focal: independent harness

LLM-free core

Graphify uses --code-only. Ollama stays out of indexing metrics so retrieval and agent behavior don’t contaminate engine timing.

Native commands

  • GitNexus 1.6.12 — analyze
  • Graphify 0.9.63 — extract
  • CodeGraph 1.6.0 — init / sync

Three phases

Cold (no state), warm (state present), incremental (one tracked file edit, then restore). One warmup, three measured runs each.

Results

Same machine, different workloads

Source census shows unequal repos — GitNexus ~3.5M LOC / 4,765 files; CodeGraph ~2.35M LOC / 713 files; Graphify ~170k LOC / 445 files. Compare medians, not single runs (GitNexus cold had a clear outlier at 132.7s).

Takeaways

The benchmark is the product

  • Execution profiles diverge sharply — cold cost ≠ warm/incremental behavior.
  • Graphify stayed consistent with the lowest RSS; CodeGraph warm/sync was sub-second here.
  • RepoAtlas stays out until methodology is stable — then same rules apply.
